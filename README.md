A two-sentence horror story for the [Two-Sentence Horror bounty on make.fun](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253).

The program (`main.ts`) writes the story to `entry.txt`: exactly two sentences, 111 characters. A child's homework comes back corrected in the narrator's own handwriting — and neither the narrator nor the teacher made the corrections. The horror is implied, never explained: someone who writes like the narrator is at the child's school.

Run it with Node 22:

```sh
node main.ts
```
